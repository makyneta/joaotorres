## Sobre o Projeto

Website pessoal de **João Torres**, atleta multieventos do **Atlético Clube da Póvoa de Varzim (ACPV)**. Uma plataforma digital que apresenta o perfil do atleta, as suas marcas pessoais, conquistas desportivas e galeria fotográfica.

### Destaques

- **Atleta Nacional** — Heptatlo, velocidade, barreiras e saltos
- **Campeão Nacional 4x100m** — Campeonato de Estafetas, Beja 2026
- **6 anos** de experiência em atletismo competitivo

---

## Secções do Site

| Secção | Descrição |
|--------|-----------|
| **Hero** | Apresentação visual com estatísticas rápidas |
| **Sobre** | Biografia e perfil do atleta |
| **Marcas Pessoais** | Scoreboard interativo com filtros por categoria |
| **Conquistas** | Linha do tempo com evolução desportiva |
| **Galeria** | Fotografias de competição com lightbox |
| **Fotografia** | Trabalho fotográfico pessoal do atleta |
| **Contacto** | Ligações para redes sociais |

---

## Stack Tecnológica

| Tecnologia | Utilização |
|------------|------------|
| **HTML5** | Estrutura semântica e acessível |
| **CSS3** | Design responsivo com custom properties |
| **JavaScript** | Interações, animações e filtros |

### Funcionalidades

- Navegação responsiva com menu mobile
- Animações de scroll reveal com `IntersectionObserver`
- Efeito parallax no hero
- Contadores animados com easing
- Filtro de categorias no scoreboard
- Lightbox com navegação por teclado
- Respeito ao `prefers-reduced-motion`
- ARIA labels e acessibilidade
